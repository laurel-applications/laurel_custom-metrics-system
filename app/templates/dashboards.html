A dashboard is a named grid of widgets. A widget visualizes one metric over a time range, so the first thing to do is to create a dashboard and then add a widget to it.

  1. Create a dashboard with the form on this page (the name is the only thing it needs).
  2. Push at least one data point for the metric you want to see. The metric is created automatically by its first ingestion, so there is no metric to create beforehand.
  3. Open the dashboard, press Add widget and pick the metric, the aggregation and the filters.

This command pushes a first data point and creates the metric requests with the tag host: 

curl -X POST {{ request.url_root }}api/ingest \
  -H 'Content-Type: application/json' \
  -d '{"name": "requests", "type": "counter", "value": 1, "tags": {"host": "web-1"}}'
